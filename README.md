While trying to use my AKAI APC MINI MK2 with QLAB's GRID, I found that Color Feedback was not available.

I created this simple python script for MacOS, which listens to the AKAI MIDI messages, sends them to QLAB, and sends color info to the AKAI. 

Inside of the script you will find inscructions to adapt the script to your own needs.

Make sure to connect the AKAI first, and that the script is running before QLab.
